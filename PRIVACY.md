# Privacy Policy

**Last Updated:** July 2026

## Introduction

Thank you for using **PR Bot Priyanshu19**.

This Privacy Policy explains what information this GitHub App accesses, how it is used, and how it is protected.

---

## Information We Access

When installed on a GitHub repository, this application may access:

- Repository metadata
- Pull request metadata
- Pull request files and code diffs
- Repository owner and repository name
- Installation information required by GitHub

---

## How We Use This Information

The accessed information is used only to:

- Analyze pull requests using AI
- Generate automated code review suggestions
- Post review comments on GitHub pull requests
- Improve the quality of automated reviews

---

## Data Storage

PR Bot Priyanshu19 does **not** permanently store:

- Source code
- Pull request contents
- Repository data
- Personal information

Temporary processing may occur only for generating AI-powered review comments.

---

## Third-Party Services

This application uses the following third-party services:

- GitHub API
- Google Gemini API

These services are governed by their own privacy policies.

---

## Data Security

Reasonable security measures are used to protect credentials and application data.

Only the minimum permissions required by the GitHub App are requested.

This Privacy Policy may be updated from time to time.

The latest version will always be available in this repository.
